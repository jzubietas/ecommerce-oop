# Proyecto eCommerce - Programación Orientada a Objetos

Este proyecto implementa una plataforma e-Commerce utilizando principios de programación orientada a objetos en Java y patrones de diseño.

## Tecnologías
- Java
- Eclipse IDE
- Patrones de Diseño: Singleton, Factory, Observer

## Cambios realizados:
- Se añadieron excepciones personalizadas (`InventarioInsuficienteExcepcion`, `PagoFallidoExcepcion`).
- Se creó la estructura de pruebas unitarias con JUnit 5.
- Se implementaron pruebas para la clase `Producto`.

## Cómo ejecutar las pruebas
Importar el proyecto en Eclipse, asegurarse de tener JUnit 5 agregado al classpath, y ejecutar las clases de prueba en la carpeta `/test`.
